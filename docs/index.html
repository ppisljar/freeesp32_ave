freeesp32_ave

An open mind-machine you can actually inspect

ESP-IDF firmware that turns an off-the-shelf ESP32 audio board into an audio-visual entrainment device: binaural and monaural beats, isochronic tones and LED photic stimulation, synthesised in real time and driven from one plain-text session script. Every number on this site was measured on the bench rather than claimed on a datasheet.

One file. One clock. Two senses.

You write a session as a .ledc text file — one line per event, absolute timestamps in milliseconds, one column per parameter. The device parses it, then executes light and sound from the same clock, which is the whole reason the two stay together. 

# t=0: 12 Hz binaural beat, amber flicker locked to it on every zone
0         12    70  60  255 50 0  255
A 0       105  -100  60   0  1      0
A 0       117   100  60   0  2      0

# 10 minutes later: glide the beat down to 7.83 Hz
600000   >7.83  70  60  255 50 0  255
A 600000 >107.085 -100 60 0  1      0
A 600000 >114.915  100 60 0  2      0

Lines with no prefix drive light; A lines drive a synthesis channel; BG adds a continuous background track and S adds spoken cues. A > or * prefix turns a value into a linear or quadratic glide to the next entry, and five more prefixes turn it into a self-contained oscillation. The full column reference lives in the session developer guide.

Measured, not claimed

Entrainment hardware is an unusually easy place to publish numbers nobody checked. These were taken off this firmware on real boards, and each one is reproducible from the reports in the repository — all of them are written up here, including the ones that are still open.

−2.7 ms audio-to-light offset, now a constant — it used to be a random 0–23 ms that re-rolled every session and jumped again at every rate change

Ten ways to present a rhythm

Entrainment means offering the brain a rhythm at a chosen frequency. There are many physical routes to that, and this firmware implements ten of them — all composable on one timeline, all documented with the column values that produce them.

Binaural beats

Two detuned carriers, one per ear. The beat is assembled inside the listener, not in the air — headphones mandatory.

Monaural beats

The same two carriers summed before the ear, so the beat is physically in the waveform. Works on a speaker.

Isochronic tones

One carrier gated on and off. The depth column decides whether that is a true pulse or a gentle tremolo.

Photic flicker

Light pulsed in front of closed eyes. Rate, duty, envelope, colour and per-zone phase, to 100 Hz.

 flagship

Antiphase “invisible” flicker

Two complementary banks 180° apart. The sum is luminance-flat, so the retina is driven but you see almost no flicker.

EEG-contour carrier

A single-cycle lookup table shaped like a recorded EEG waveform rather than a geometric tone. Six harmonics by construction.

AM noise

Pink or brown noise gated at the target rate. Broad cochlear drive, low fatigue — the usual choice for sleep.

Split-field, per eye

A different rate to each eye through the channel mask — the two hemifields get their own frequency.

Traveling-wave phase gradients

A phase step per zone turns eight separate flashes into motion across the field. Form constants are strongest near 10 Hz.

Anti-habituation jitter

A slow bipolar wander on the beat or flicker rate, so the response does not adapt away over a long hold.

Each of these is a column pattern, not a mode switch — see the techniques guide for the exact values, and the complete reference for every column they use.

Read before you build or use this

This device deliberately flashes light in the 3–30 Hz band. That band is a genuine seizure trigger for people with photosensitive epilepsy, and bright flicker around 15–25 Hz is the risk peak; saturated red is a special case of its own. Do not use it — and do not point it at anyone — if there is any history of epilepsy, seizures or photosensitivity in the user or their family, and stop immediately on any aura, nausea, disorientation or involuntary movement.

The firmware contains no safety interlock. A brightness/depth clamp for the high-risk band was designed and deliberately left unimplemented, so a session file can command any rate and brightness the hardware can produce. The one gate that ships is a one-time notice in the browser, which means a session played from the SD card with no browser attached has no gate at all. The authoring discipline is yours, not the device's.

This is a DIY research and meditation instrument built by hobbyists. It is not a certified medical device, it has no clinical validation, and nothing here is medical advice or a treatment claim.
