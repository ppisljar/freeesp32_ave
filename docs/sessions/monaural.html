Monaural beats

The same two detuned carriers as a binaural beat, but summed before they reach the ear. The beat is then a real amplitude modulation, physically present in the air and in any recording — so a single speaker, or one earbud, carries all of it.

What the phenomenon is

Add two sine waves of similar frequency and the result is a single tone whose amplitude rises and falls at the difference frequency. 200 Hz plus 208 Hz gives you one 204 Hz-ish tone whose loudness swings fully from maximum to zero and back eight times a second. That swing is ordinary interference, the same arithmetic that makes two slightly mistuned guitar strings “wobble”. No perceptual machinery is involved.

The top two lanes are two carriers, eight and nine cycles long over the same span, both panned centre so both reach both ears. The bottom lane is their arithmetic sum: the envelope collapses to nothing once across the frame, which is the beat. Compare the binaural figure, where the equivalent envelope had to be drawn dashed because it existed nowhere in the signal. Here it is the signal. This is the whole difference between the two modalities, and it is also why the modulation is so much deeper.

The depth difference is the headline number. A monaural beat's envelope modulation approaches 100 % — around 50 dB of swing between peak and null. A binaural beat's effective modulation is around 3 dB. The two are the same rate delivered with roughly an order of magnitude's difference in contrast.

Mechanism, as currently understood

Here the physics is not in question — the stimulus genuinely contains an amplitude modulation at the target rate, so the cochlea and the auditory nerve are driven at that rate directly, exactly as they would be by an isochronic tone. The measurable auditory steady-state response to a monaural beat is reliably larger than to a binaural beat of the same rate and carrier, and comparative work on the two generally finds monaural the stronger driver.

What remains thin is the same thing that is thin everywhere in this field: the link from “there is a stronger steady-state response at 6 Hz” to “the listener is therefore in a theta state, with the subjective and behavioural properties attributed to theta”. A bigger evoked response is not automatically a bigger psychological effect, and the studies that look for mood, anxiety or cognitive outcomes from beat stimulation are small, often unblinded, and frequently null. Use monaural because it is the more honest and more robust physical stimulus, not because the outcome literature is settled. It is not.

One real trade-off: because the modulation is deep and audible, a monaural beat sounds like something. It is a pulsing, slightly rough tone, not a smooth drone. For sleep content that can be a liability, which is why the shipped library reserves binaural for the sleep arcs and uses monaural for drumming and waking work.

What it is typically used for

  • Speaker playback of any kind. This is the only beat modality that survives it. Pillow speakers, a desk speaker, a bone-conduction transducer, one earbud while lying on the other ear.
  • Waking states — focus, energise, alertness — where you want the strongest available auditory drive and do not mind hearing the pulse.
  • Drum-trance and journeying work. The shipped 36_shamanic_trance_drum.ledc is the canonical example: a steady ~4.5 Hz monaural drum held for sixteen minutes, chosen specifically because it is “the stronger, more robust driver, ideal for a hands-free journeying drum”, per its own header. Its research note points at the finding that a steady ~4–4.5 Hz drum held for at least fifteen minutes reliably shifts practitioners into a theta trance.
  • Layering. Because both carriers are centre-panned, a monaural pair leaves pan entirely free for other channels — a rotating-pan noise bed, say — in a way a hard-panned binaural pair does not.

If your session also flickers light anywhere in the 3–30 Hz band — and a 4.5 Hz drum session locked 1:1 to the LEDs does — then the photosensitivity warning applies in full. Flickering light in that band is a genuine seizure trigger for susceptible people, worst between 15 and 25 Hz. Do not use, and do not hand a session to anyone who has any history of photosensitive epilepsy, a seizure disorder, or photic migraine. See safety. This is a DIY research instrument, not a medical device.

How to configure it in .ledc

There is no beat_mode column and no monaural macro in the format. A monaural beat is two audio channels, both at pan 0, whose carriers differ by the beat rate. The summing happens in the device's mixer and then in the air; the format does not need to know about it.

#         time  freq  pan  vol  mod  ch  freqR  waveType
A            0   200    0   45    0   1      0         0   # anchor carrier
A            0   208    0   45    0   2      0         0   # => 8 Hz beat

Four things about that pair are load-bearing:

The four constraints on a monaural pair.
RequirementWhy
pan 0 on both Both carriers must arrive at both ears at equal level or the sum is no longer a full-depth beat. Any non-zero pan attenuates one carrier in one ear and shallows the null on that side.
freqR 0 on both These are mono channels. A non-zero freqR would trip the binaural-bypass path, skip the pan stage, and route the two carriers to opposite ears — turning your monaural pair into two accidental binaural channels.
matched vol The null is only complete when the two amplitudes are equal. Unequal volumes leave a residual carrier at the null and shallow the modulation.
two different ch numbers One channel cannot hold two carriers in the mono path; freq and freqR on one channel is the binaural idiom, not this one.

Rows sharing one timestamp start phase-coherent. Each timestamp dispatches in three passes — all audio first, then all LED, then everything else — specifically so that audio channels armed in the same batch begin together. Put both halves of a monaural pair on the same timestamp and you get a predictable initial beat phase. Split them across two timestamps and the beat's phase at onset is whatever the gap happens to produce.

Gliding the beat

Move one carrier and leave the other as an anchor. Both freq columns are fully compound, so a > on either one ramps it:

A       120000   200    0   45    0   1      0         0   # ch1 stays put
A       120000  >208    0   45    0   2      0         0   # ch2 ramps 208 -> 204.5
A       420000   200    0   45    0   1      0         0   # anchor, unchanged
A       420000 204.5    0   45    0   2      0         0   # target: beat is now 4.5 Hz

Moving one carrier rather than both keeps the perceived pitch nearly fixed while the beat slides 8 → 4.5 Hz. Moving both in opposite directions would also work and would hold the pitch exactly, at the cost of twice as many rows to keep consistent.

Write the anchor row at the ramp's target timestamp too, even though nothing changes on it. The ramp target for a compound core field is read from the next entry on that channel, so each channel needs an entry at the end of the glide — and an explicit row is also what stops a later edit from silently re-pointing the ramp somewhere unintended.

Anti-habituation

Sixteen minutes of an unvarying 4.5 Hz drum habituates, which is the problem anti-habituation wander exists to solve. On a monaural pair, audio jitter is the wrong tool: it only ever moves a binaural detune and is gated on freqR > 0, so on these mono channels it does nothing at all. Three options that do work:

  • Modulate one carrier with a periodic glyph, so the beat itself breathes: ~204:205:53000 on freq makes the beat wander between 4 and 5 Hz over 53 seconds.
  • Put the jitter on the light, which is per-mask and does wander the flicker rate: jitter 0.3:53000 in the LED line's twelfth column.
  • Add a jittered isochronic layer on a third channel, as 36_shamanic_trance_drum.ledc does — though note that session's own header claims the jitter wanders its isochronic pulse rate, which is not what the audio jitter column does. See the trap list.

Use non-commensurate periods — 37 s and 53 s rather than 30 s and 60 s — so the layers do not re-synchronise into an audible super-period. Any period_ms under 1000 is silently ignored.

Locking light to the beat

Write the same rate in the LED line's freq column. There is no automatic link:

A       420000   200    0   45    0   1      0         0   # anchor
A       420000 204.5    0   45    0   2      0         0   # beat = 4.5 Hz
       420000   4.5   50   22  220  110     0    15    3  0  6   # LED 4.5 Hz, trapezoid, 6 ms edge

A percussive beat pairs naturally with a percussive flash — env 3 (trapezoid) with a few milliseconds of attack gives a crisp edge without a click, which is what 36_shamanic_trance_drum uses for its “drum flash”. A smooth env 1 sine gate would fight the character of the audio.

Remember that a glide must be written on both lines. A > on the audio carrier and a bare number on the LED line gives you an audio beat sliding away from a static light rate.

Complete worked example

monaural_theta_drum.ledc — 20 minutes, 8 Hz settle, glide to a 4.5 Hz drum, hold, faster “callback”, close. It reports no static problems found under python3 tools/avmeasure/analyze.py lint.

# --- Induction, 8 Hz (00:00-02:00) ---
0 8 50 >0 220 110 0 15 3 0 6          # amber trapezoid "drum flash", 6 ms edge; bright 0 -> 22
A 0 200 0 >0 0 1 0 0                  # ch1 anchor carrier 200 Hz, centre; vol ramps 0 -> 45
A 0 208 0 >0 0 2 0 0                  # ch2 carrier 208 Hz, centre => 8 Hz beat in the air
15000 8 50 22 220 110 0 15 3 0 6      # brightness reaches the 22% cap
A 60000 200 0 45 0 1 0 0              # ch1 vol settled 45
A 60000 208 0 45 0 2 0 0              # ch2 vol settled 45 (matched levels => deepest beat)

# --- Deepen, beat 8 -> 4.5 Hz over 5 min (~0.7 Hz/min) (02:00-07:00) ---
A 120000 200 0 45 0 1 0 0             # ch1 stays put: only ONE carrier moves
A 120000 >208 0 45 0 2 0 0            # ch2 ramps 208 -> 204.5 => beat 8 -> 4.5
120000 >8 50 22 220 110 0 15 3 0 6    # light tracks the beat 1:1

# --- Hold, 4.5 Hz, 10 min (07:00-17:00) ---
A 420000 200 0 45 0 1 0 0             # anchor held
A 420000 204.5 0 45 0 2 0 0           # beat held flat at 4.5 Hz
420000 4.5 50 22 220 110 0 15 3 0 6   # 4.5 Hz amber flash, 1:1 with the drum

# --- Callback, 4.5 -> 9 Hz (17:00-19:00) ---
A 1020000 200 0 45 0 1 0 0
A 1020000 >204.5 0 45 0 2 0 0         # ch2 204.5 -> 209 => beat 4.5 -> 9
1020000 >4.5 50 22 220 110 0 15 3 0 6

# --- Close (19:00-20:00) ---
A 1140000 200 0 >45 0 1 0 0           # both carriers fade together
A 1140000 209 0 >45 0 2 0 0
1140000 9 50 >22 220 110 0 15 3 0 6
A 1200000 200 0 0 0 1 0 0
A 1200000 209 0 0 0 2 0 0
1200000 9 50 0 220 110 0 15 3 0 6

Note that both carriers fade together at the close. Fading only one would not fade the beat — it would deepen the imbalance, shallow the modulation, and leave a bare carrier audible at the end. Monaural pairs always move together on vol.
